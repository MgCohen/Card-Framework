# Sessions

This folder is a **sparse milestone archive**. Session notes are no longer mandatory — `SESSION-CHECKPOINT.md` is the single live spine and is updated continuously as work happens.

When a piece of state is worth freezing as a milestone, run `/builder:snapshot` and a copy of the checkpoint lands here as `session-<UTC-YYYYMMDD>-<HHMM>-<slug>.md`. Otherwise nothing lands here.

Legacy per-session notes (the original mandatory schema, ~2026-04 through 2026-05) live in [`Product/_archive/sessions/`](../_archive/sessions/) — preserved as historical record, not migrated.

See `PLANS/simplify-doc-workflow.md` decision #6 for the rationale.

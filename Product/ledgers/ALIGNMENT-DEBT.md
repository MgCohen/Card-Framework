### Cascade — Objects-over-IDs audit (ADR-0005, session-20260501-1602)

Driven by [ADR-0005](decisions/0005-objects-over-ids.md). The ADR established the "Objects over IDs" principle — framework APIs prefer domain objects (`Zone`, `StateEntity`, `Actor`) over `Identifier<T>` values, with IDs reserved for boundaries (serialization, persistence, network, type-mismatch). A grep sweep across `features/` surfaced numerous non-boundary uses of `InstanceId`, `ActorId`, `ZoneId`, `PileId`, `DefinitionId` in API positions. Each Model needs a focused audit pass that distinguishes boundary uses (Commands as wire-form, Mutator payloads, ActionTemplates in snapshots, Presentation as snapshot consumer) from non-boundary uses (handler/effect/rule callbacks, `GameRules` method signatures, registration APIs).

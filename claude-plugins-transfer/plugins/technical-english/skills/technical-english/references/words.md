# Word substitutions

Common words that are not approved in STE, and an approved word or phrase to use. This is a short
working list, not the ASD-STE100 dictionary. If you are not sure about a word, use the simplest
common word with one clear meaning, and confirm in the dictionary of the current issue.

| Do not use | Use |
|---|---|
| accomplish, perform, carry out | do |
| additional | more |
| adjacent | near, next to |
| allow, permit (to let something happen) | let |
| approximately | about |
| assist | help |
| attempt | try |
| be able to | can |
| check (verb) | examine, make sure |
| commence, initiate | start |
| comprise, consist of | contain, have |
| due to | because of |
| ensure | make sure |
| facilitate | help, make … easier |
| find out | find, identify |
| in order to | to |
| indicate | show |
| leverage, utilize | use |
| locate | find |
| modify | change |
| necessitate, require | need, is necessary |
| numerous | many |
| obtain | get |
| prior to | before |
| provide | give, supply |
| regarding | about |
| retain | keep |
| set up | install, prepare |
| subsequently | then, after |
| sufficient | enough |
| terminate | stop |
| verify | make sure, examine |
| via | through, with |

## Style substitutions

| Do not write | Write |
|---|---|
| "It should be noted that X." | "X." or "Note: X." |
| "You will want to run the gate." | "Run the gate." |
| "The file is read by the loader." | "The loader reads the file." |
| "Make a change to the config." | "Change the config." |
| "Running the gate, the build fails." | "When you run the gate, the build fails." |
| "Don't" / "can't" / "it's" | "Do not" / "cannot" / "it is" |
